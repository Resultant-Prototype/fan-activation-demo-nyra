The Problem
5 systems. No shared answer to who can actually be contacted.
Ticketmaster
Ticket buyer preferences live in the box office system. Marketing never sees them.
ADW
Wagering accounts carry their own opt-in flag, and the one signal that can never be ignored: self-exclusion. Neither reaches any other system.
Marketing (Optimove / Mailchimp / HubSpot)
The email platform tracks unsubscribes, but only for its own list. It has no idea what any other system already promised a customer.
F&B (Shift4 / Spot On)
Concession purchases sit in their own system, with no link back to a person's marketing preferences.
Unsubscribe roster
A standalone do-not-contact list exists. Half the systems above have never checked it.

None of this is a data quality problem. It's that no single system was ever built to answer one question: can NYRA actually contact this fan.
